CLI Calculator Application
A modular, terminal-based calculator written in Python for multi-value arithmetic operations.

Features
Performs addition, subtraction, multiplication, and division
Accepts two or more numbers in a single calculation
Validates numeric input and handles invalid entries gracefully
Prevents crashes on division by zero
Logs session calculation history
Terminal menu navigation

How to Run
Run the following command in your terminal:
python calculator.py

Concepts Used
Functions and modular program design
While and for loops
Dictionary dispatch and conditional statements
Lists and list slicing
Console input and string processing
Exception handling
